# 🤖 AI Code Reviewer

An intelligent, AI-powered code review web application that analyzes source code and provides constructive feedback using natural language. Built to enhance developer productivity, spot potential bugs, and follow best practices — all in real time.

---

## 🧠 Overview

The **AI Code Reviewer** allows users to input or paste their code and receive instant AI-generated feedback. It’s designed for developers who want to improve their code quality with the help of large language models (LLMs), without waiting for human code reviews.

---

## ⚙️ Tech Stack

- **Frontend:** React, TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **AI Engine:** Gemini API (Google AI Studio or Cloud API)
- **State Management:** React Hooks (with Context API)

---

## ✨ Features

- 🧠 **LLM-Powered Reviews**  
  Automatically detects code smells, inefficiencies, or bad practices using AI.

- ✍️ **Multi-Language Support**  
  Works with JavaScript, TypeScript, Python, C++, and more (based on AI capability).

- ⚡ **Real-Time Response**  
  Instantly provides suggestions with minimal latency using Gemini API.

- 🧪 **Suggestions, Fixes & Complexity Tips**  
  Offers rewrite suggestions, time complexity estimation, and optimization strategies.

- 🎨 **Modern, Responsive UI**  
  Built with Tailwind CSS and animated transitions using Framer Motion.
